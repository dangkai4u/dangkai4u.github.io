## 代码重构

当面对一个复杂的遗留代码库时，Claude Code 可以快速理解上下文并提供重构建议。比如将一个 500 行的函数拆分成多个职责清晰的小函数，它能保持逻辑一致性的同时优化代码结构。

## 调试辅助

遇到诡异的 bug 时，把错误日志和相关代码丢给它，往往能直接定位到问题根因。尤其是并发相关的问题，人工排查可能需要几个小时，AI 几秒就能给出方向。
